Netflix UI

Changes apply the next time a client loads the home screen. The theme itself comes from the plugin, so there is nothing to paste into Branding.

Big rotating banner at the top of home.
Desktop only. Needs trailer files next to the movie.
Top 10 movies and shows on this server, last 30 days.
A title is only ranked when at least this many different people played it, so nobody's own viewing is shown to everyone. The rest of the row is filled with well rated titles. 1 turns this off.
Rows built from the genres each person watches most. 0 turns them off.
Desktop with a mouse only.

Leave these libraries out

Nothing from a ticked library shows in the hero, Top 10 or genre rows. Good for Demos or home videos. Items with no TMDb, IMDb or TVDb id are always left out.
Leave on, and leave Branding custom css empty. Setting both loads the theme twice.
